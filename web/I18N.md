# 국제화(i18n) 가이드

이 문서는 UISCloud Onyx 웹 앱의 다국어(한국어/영어) 지원 구현에 대해 설명합니다.

## 개요

- **라이브러리**: `next-intl` v4.8.3
- **지원 언어**: 영어(`en`, 기본값), 한국어(`ko`)
- **언어 전환 방식**: URL 변경 없음 (`localePrefix: 'never'`), `NEXT_LOCALE` 쿠키로 감지
- **번역 파일 위치**: `web/src/messages/en.json`, `web/src/messages/ko.json`

---

## 핵심 파일

| 파일 | 역할 |
|---|---|
| `src/i18n/routing.ts` | locale 목록 및 라우팅 설정 |
| `src/i18n/request.ts` | 서버사이드 쿠키 기반 locale 감지 |
| `src/messages/en.json` | 영어 번역 파일 |
| `src/messages/ko.json` | 한국어 번역 파일 |
| `src/components/LanguageSwitcher.tsx` | 앱 내 언어 선택 컴포넌트 (설정 팝오버) |
| `src/components/auth/LoginLanguageSwitcher.tsx` | 로그인 페이지 언어 선택 컴포넌트 |
| `src/components/auth/AuthFlowContainer.tsx` | 언어 선택기가 포함된 인증 레이아웃 |
| `src/app/layout.tsx` | `NextIntlClientProvider` 마운트 위치 |
| `next.config.js` | `createNextIntlPlugin` 적용 |

> **주의**: `middleware.ts` 없음. Next.js 16 Turbopack standalone 빌드 버그로 인해 삭제됨.
> locale은 `src/i18n/request.ts`에서 `cookies()`로 직접 읽음.

## 번역 사용법

### 클라이언트 컴포넌트

```tsx
"use client";
import { useTranslations } from 'next-intl';

function MyComponent() {
  const t = useTranslations('namespace');
  return <span>{t('myKey')}</span>;
}
```

### 서버 컴포넌트

```tsx
import { getTranslations } from 'next-intl/server';

async function MyPage() {
  const t = await getTranslations('namespace');
  return <span>{t('myKey')}</span>;
}
```

### 변수 보간

```tsx
// en.json: "greeting": "Hello, {name}!"
t('greeting', { name: 'John' }) // → "Hello, John!"

// en.json: "minLength": "At least {min} characters"
t('minLength', { min: 8 }) // → "At least 8 characters"
```

### 리치 텍스트 (HTML 태그 포함)

```tsx
// en.json: "info": "Click <link>here</link> to continue"
t.rich('info', {
  link: (chunks) => <a href="/path">{chunks}</a>
})
```

## 새 번역 키 추가 방법

1. `en.json`에 영어 키 추가
2. `ko.json`에 동일 키로 한국어 번역 추가
3. 컴포넌트에서 `t('namespace.key')` 사용

```json
// en.json
{
  "admin": {
    "myNewKey": "My New Text"
  }
}

// ko.json
{
  "admin": {
    "myNewKey": "새 텍스트"
  }
}
```

## 언어 전환 UI

### 로그인 페이지
`AuthFlowContainer`의 우상단에 `LoginLanguageSwitcher` 컴포넌트가 렌더링됩니다.
- `EN` 버튼: 영어 선택 (활성 시 배경 강조)
- `KO` 버튼: 한국어 선택 (활성 시 배경 강조)

### 앱 내부 (로그인 후)
좌측 사이드바 하단 사용자 아이콘 → 팝오버 메뉴에 `LanguageSwitcher` 컴포넌트 표시.
- **English** (활성 시 체크 아이콘 + 배경 강조)
- **한국어** (활성 시 체크 아이콘 + 배경 강조)

### 동작 방식
1. 언어 선택 시 `NEXT_LOCALE` 쿠키 설정 (1년 유효)
2. `router.refresh()` 호출로 서버 컴포넌트 재렌더링
3. `src/i18n/request.ts`가 쿠키를 읽어 해당 locale의 번역 파일 로드

## 주의사항

- `useTranslations`는 컴포넌트 최상단에서 한 번만 호출 (JSX 인라인 호출 금지)
- `"use client"` 없는 컴포넌트에서 `useTranslations` 사용 시 빌드 오류 발생
- 헬퍼 함수에서 번역이 필요한 경우 `t` 함수를 파라미터로 전달
- `dark:` Tailwind 클래스와 마찬가지로 번역 파일의 기존 키는 절대 변경하지 말 것
